# Remote — управление компьютером с телефона

**remote.aiternitas.ru**

На телефоне вы видите **экран компьютера в реальном времени** и управляете им касаниями. Можно записывать макросы (быстрые действия) на компьютере и запускать их с телефона одним нажатием.

## Установка

```bash
cd remote-control
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Запуск

```bash
python -m server.main
```

Или двойной клик по `run.bat` (Windows).

Откройте на телефоне: `http://<IP-компьютера>:8765`

## Как пользоваться

### На телефоне
- **Тап** — клик левой кнопкой мыши
- **Долгое нажатие** — клик правой кнопкой
- **Перетаскивание пальцем** — движение курсора
- **Два пальца** — скролл
- **Быстрые действия** — макросы, записанные на компьютере
- **Клавиши** — Tab, Пробел, Enter, ввод текста

### Запись макросов (на компьютере)
1. Откройте `http://localhost:8765/record`
2. Нажмите **Записать**
3. Выполните нужные действия (клики, клавиши, открытие программ)
4. Нажмите **Стоп**
5. Введите название (например: «Запуск Dota») и **Сохранить**

Макрос появится в «Быстрых действиях» на телефоне — одно нажатие воспроизведёт всю последовательность.

## Примеры макросов
- Запуск игры (клики по иконке, кнопкам)
- Открытие браузера и нужной вкладки
- Переключение между программами
- Любая повторяющаяся последовательность действий

## Безопасность
Используйте только в локальной сети. Не открывайте порт 8765 в интернет без защиты.
