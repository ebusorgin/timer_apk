# Расширение Chrome — net.aiternitas.ru

Показывает **Bluetooth** (включен/выключен), **сеть** (Wi‑Fi / 4G и т.д.) и позволяет искать BLE-устройства.

## Установка

1. Откройте в Chrome: **chrome://extensions/**
2. Включите **«Режим разработчика»** (переключатель справа вверху).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Укажите папку **`chrome-extension`** (та, где лежит `manifest.json`).

Путь к папке на вашем компьютере:
```
…\net.aiternitas.ru\chrome-extension
```

5. Расширение появится в списке. Иконку можно закрепить на панели (нажать на значок пазла → закрепить «net.aiternitas.ru — каналы»).

## Как пользоваться

- Нажмите на иконку расширения → откроется попап.
- **Bluetooth** — включен / выключен (Web Bluetooth API).
- **Сеть** — Wi‑Fi, 4G, Ethernet и т.п.
- **«Найти устройство по BLE»** — откроется системный выбор устройства; выбранное устройство добавится в список.
- Ссылка **«Открыть приложение»** ведёт на https://net.aiternitas.ru/app

## Файлы

- `manifest.json` — манифест (Manifest V3).
- `popup.html`, `popup.css`, `popup.js` — попап с состоянием каналов и кнопкой поиска BLE.
- `icons/` — иконки 16, 48, 128 px.
