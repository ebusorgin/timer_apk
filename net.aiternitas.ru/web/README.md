# Веб-версия net.aiternitas.ru

Лендинг (вход/регистрация), контакты (NodeID + ключи), сообщения.

## Локально

1. Запустить сервер (релей + API): из корня проекта `npm start` (порт 3000).
2. Запустить фронт с прокси: `npm run dev` (порт 5173). Открыть http://localhost:5173.
3. Или собрать и раздавать с сервера: `npm run build`, затем сервер раздаёт `web/dist` по корню.

## Регистрация и контакты

- Регистрация создаёт учётную запись (username + password) и узел (identity). Identity хранится на сервере в сессии (после перезапуска — повторный вход).
- Контакты — это NodeID и box public key (base64). Добавлять вручную (скопировать NodeID и ключ от другого узла) или обменяться вне приложения.

## Тесты

Из корня: `npm test` — включая тесты веб-API (register, login, contacts, build message).
