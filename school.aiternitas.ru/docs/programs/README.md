# Программы обучения

Программы хранятся в БД (схема school_aiternitas_ru). Управление через админ-панель или seed-скрипты.

## Таблицы

- `school_types` — типы школ (техническая, художественная)
- `programs` — программы с направлениями, возрастом, длительностью

## Сиды

- `npm run seed-school-types` — типы школ
- `npm run seed-programs` — дефолтные программы (из кода)

## Возрастные группы

| Возраст | Формат |
|---------|--------|
| 5–7 лет | Игровой, короткие занятия |
| 8–10 лет | Модули по 8–12 занятий |
| 11–13 лет | Годовые курсы |
| 14+ лет | Углублённые курсы |
